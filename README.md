# 📊 Data Visualization for Sales Analysis

> Exploratory data analysis and visualization of sales data using Python  
> Built in Jupyter Notebooks · 100% Python

---

## 🧠 What It Does

- Loads and cleans a sales dataset
- Performs exploratory data analysis (EDA)
- Generates visualizations to uncover:
  - Sales trends over time
  - Top performing products / categories
  - Revenue distribution
  - Key business insights

## 🚀 How to Run

```bash
git clone https://github.com/ehhsen/Data-Visualization-for-Sales-Analysis-.git
cd Data-Visualization-for-Sales-Analysis-

# Install dependencies
pip install numpy pandas matplotlib seaborn jupyter

# Launch notebooks
jupyter notebook
```

Open `sales_analysis.ipynb` and run all cells top to bottom.

---

## 📌 Notes

- Make sure the dataset file is in the correct path before running
- All visualizations render inline inside the notebook
- Run cells in order to avoid dependency errors
